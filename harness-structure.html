Repository Harness for Coding Agents

Minh họa cách repo này biến ý định của human thành story, proof, trace, audit và improvement loop cho coding agent.

Operating Flow

Human Intent Prompt, spec, change request, maintenance request.
Feature Intake Phân loại input type và lane tiny / normal / high-risk.
Context Rules Đọc đúng file theo phase, lane và retrieval trigger.
Story Packet Mô tả contract, design, validation, risk và evidence.
Agent Work Implement, update docs, run proof, giữ đúng boundaries.
Trace + Matrix Ghi actions, files, outcome, friction và proof status.
Audit + Propose Tìm drift, entropy, repeated friction và tạo backlog.

Entrypoint

AGENTS.md / CLAUDE.md

Shim ngắn để agent biết phải đọc README, Harness docs, context rules, tool registry và matrix trước khi làm việc.

Policy Docs

docs/HARNESS.md + FEATURE_INTAKE.md

Định nghĩa task loop, input types, risk lanes, done definition, growth rule và khi nào cần story/decision.

Durable Layer

SQLite + Rust CLI

harness.db lưu intakes, stories, decisions, backlog, traces, tools và interventions. Schema nằm trong scripts/schema.

Runtime Gap

Missing Binary

Workspace hiện tại không có scripts/bin/harness-cli.exe và không có cargo, nên CLI không chạy được trong scan này.

Lane Model

  • Tiny: docs/copy/narrow edits.
  • Normal: bounded story-sized work.
  • High-risk: auth, data, contracts, security, providers.

Proof Columns

  • Unit
  • Integration
  • E2E
  • Platform
  • Evidence

Evolution Loop

Trace friction + intervention + audit drift -> harness-cli propose -> backlog item -> implementation -> close với actual outcome.

Core Components

Task Spec

Intake + Stories

Biến prompt thành work item có lane, affected docs, story id, validation và acceptance criteria.

Context

Context Rules

Hướng dẫn đọc đúng nguồn theo phase, tránh nhầm giữa docs, decisions, product truth và code.

Verification

Matrix + Verify

Story có proof flags và optional verify command; verify-all gom bằng chứng trước close/merge.

Memory

Decisions + Trace

ADR, backlog và traces giữ lại lý do, kết quả, friction và intervention cho lần chạy sau.

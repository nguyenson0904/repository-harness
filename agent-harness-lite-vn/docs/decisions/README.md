# Decisions

Decision records ghi lại các lựa chọn cần tồn tại lâu hơn một task.

Tạo decision khi work thay đổi:

- hướng kiến trúc,
- database ownership hoặc schema strategy,
- API shape,
- auth hoặc authorization behavior,
- audit/security behavior,
- validation requirements,
- source-of-truth hierarchy.

Dùng `docs/templates/decision.md`.

Tên file khuyến nghị:

```text
docs/decisions/0001-stack-selection.md
docs/decisions/0002-order-data-model.md
```

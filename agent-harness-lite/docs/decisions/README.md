# Decisions

Decision records capture choices that should outlive one task.

Create a decision when work changes:

- architecture direction,
- database ownership or schema strategy,
- API shape,
- auth or authorization behavior,
- audit/security behavior,
- validation requirements,
- source-of-truth hierarchy.

Use `docs/templates/decision.md`.

Recommended naming:

```text
docs/decisions/0001-stack-selection.md
docs/decisions/0002-order-data-model.md
```
